# Font attribution

Each font directory contains its license. Kalam is a handwriting-style Devanagari family; MarathiCursive is a Unicode Modi font; Sharada uses the Noto Sans design, which has broad Unicode coverage.

- Kalam, regular style from Google Fonts: https://github.com/google/fonts/tree/main/ofl/kalam
- MarathiCursive v2.1: https://github.com/MihailJP/MarathiCursive/releases/tag/v2.1
- Noto Sans Sharada, release `NotoSansSharada-v2.006`: https://github.com/notofonts/sharada/releases/tag/NotoSansSharada-v2.006
- Additional Noto Sans Devanagari and Modi fonts are included as licensed alternatives.
- Satisar Sharada is included as an experimental alternative; its authors note that it is not production ready: https://github.com/virtualvinodh/satisarsharada
